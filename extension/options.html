T2K

Twitch → Kick · mode simple

Comment ça marche

  • Sans clé crypto — le streamer tape uniquement son trigger dans le chat.
  • Sécurité = seul le streamer (badge / pseudo) peut déclencher le raid.
  • Il doit être en live sur sa chaîne Twitch (source).
  • Les viewers avec l’extension voient une bannière 3 s puis partent vers Kick (cible).

1. Définis source & cible

Sur twitch.tv/… → tape : … → kick.com/…

Envoyer au registre (e-mail)

L’extension lit le registre public streamers.json. Envoie ta config à 2hellv@gmail.com pour être ajouté — sans ça, les viewers ne connaissent pas ton trigger / ta cible.

2. Côté viewers

  • Installer cette extension (mode développeur → dossier extension/).
  • Regarder ton live Twitch.
  • Quand tu tapes le trigger, bannière → Kick.

3. Pendant le live

  • Sois en direct (badge live).
  • Sur ta chaîne source.
  • Envoie uniquement le trigger (rien d’autre sur la ligne).
  • Exemple : #t2k#
