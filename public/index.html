T2K

Twitch → Kick

Une phrase anodine dans le chat du streamer → les viewers avec l’extension partent sur Kick. Réglages dans le popup : Source, Cible, Timer.

Télécharger

Paquet prêt pour Chrome (v3.1.1) — ZIP = format Chrome Web Store. CRX = même extension, signée localement (hors boutique Chrome bloque souvent l’install directe du CRX).

Télécharger T2K.zip Télécharger T2K.crx

Recommandé : le ZIP + installation manuelle ci-dessous.

Installer dans Chrome / Edge

  1. Télécharge T2K.zip et décompresse-le (tu dois voir un dossier avec manifest.json dedans).
  2. Ouvre chrome://extensions (ou edge://extensions).
  3. Active le Mode développeur (en haut à droite).
  4. Clique Charger l’extension non empaquetée.
  5. Sélectionne le dossier décompressé (celui qui contient manifest.json).
  6. L’icône T2K apparaît dans la barre — clique pour configurer Source / Cible / Timer.

Après une mise à jour du ZIP : remplace les fichiers du dossier, puis clique Actualiser sur la carte T2K dans chrome://extensions.

Réglages

  • Source — login Twitch (chaîne live à écouter)
  • Cible — login Kick (destination)
  • Timer — secondes de la bannière avant redirect

Streamer et viewers doivent avoir la même Source / Cible. Modifiable à tout moment (onglet Réglages).

Streamer

  1. Installe l’extension → ouvre T2K → configure Source / Cible / Timer.
  2. En live sur la Source : Copier une phrase → colle-la telle quelle.

Viewer

  1. Même extension + mêmes réglages Source / Cible.
  2. Regarde le live → bannière → Kick (Échap = annuler).
