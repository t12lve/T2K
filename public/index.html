T2K

Twitch → Kick · mode simple (sans clé)

Idée

Le streamer tape uniquement un trigger dans le chat (ex. #1212#). Les viewers avec l’extension partent vers Kick. Pas de token, pas de crypto, pas de .bat.

Sécurité (sans clé)

  • Seul le streamer (pseudo / badge broadcaster) peut déclencher.
  • Il doit être en live (indicateur live sur la page).
  • Il doit être sur sa chaîne source Twitch.
  • La cible Kick est définie dans le registre (sinon = même login).

Pas à pas streamer

1 · Config
  1. Installe l’extension Chrome (mode développeur → dossier extension/).
  2. Clique l’icône T2K → page Onboarding.
  3. Renseigne : chaîne source Twitch, chaîne cible Kick, trigger.
  4. Envoie la config au registre (2hellv@gmail.com) pour publication dans streamers.json.
2 · Pendant le live
  1. Lance ton live sur ta chaîne.
  2. Dans le chat, envoie seulement le trigger, ex. :
#1212#

Pas d’URL, pas de token. Une ligne = le trigger. Désactive le Mode Anonyme.

3 · Viewers

Ils installent la même extension et regardent ton live. Bannière 3 s (vert Kick) → redirection. Escape = annuler.

Exemple registre

{
  "streamers": {
    "t12lve": {
      "displayName": "t12lve",
      "trigger": "#1212#",
      "target": "t12lve"
    }
  }
}

Fichier public : streamers.json — pas de clé privée dedans.

Si ça ne marche pas

  • Pas en live / pas sur ta chaîne / pas le streamer qui tape
  • Trigger avec du texte en plus sur la même ligne
  • Pas encore dans streamers.json publié
  • Extension non rechargée après mise à jour
