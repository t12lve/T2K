T2K

Twitch → Kick

Une phrase anodine dans le chat du streamer → les viewers avec l’extension partent sur Kick. Réglages dans le popup : Source, Cible, Timer.

Réglages

  • Source — login Twitch (chaîne live à écouter)
  • Cible — login Kick (destination)
  • Timer — secondes de la bannière avant redirect

Streamer et viewers doivent avoir la même Source / Cible. Modifiable à tout moment (onglet Réglages).

Streamer

  1. Installe l’extension → ouvre T2K → configure Source / Cible / Timer.
  2. En live sur la Source : Copier une phrase → colle-la telle quelle.

Viewer

  1. Même extension + mêmes réglages Source / Cible.
  2. Regarde le live → bannière → Kick (Échap = annuler).
