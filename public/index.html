C’est quoi T2K ?

Imagine que tu fais un live sur Twitch et que tu veux envoyer ton chat vers une autre plateforme (souvent Kick).

Le problème : n’importe qui pourrait écrire dans le chat allez tous sur mon-site-chelou.com. Ce serait dangereux.

T2K règle ça avec une idée simple :

Seul toi (le streamer) peux créer un message !raid … authentique, grâce à une « signature » secrète. L’extension des viewers vérifie cette signature avant d’afficher un bouton de redirection.

Analogie : ta clé privée = le tampon de mairie. Ta clé publique = le modèle que tout le monde peut utiliser pour vérifier que le tampon est vrai. Personne ne peut fabriquer ton tampon.

1. Tu signes un raid sur ton PC
↓
2. Tu colles !raid dans le chat Twitch
↓
3. L’extension vérifie → bannière 3 secondes
↓
4. Le viewer est redirigé (ou appuie sur Échap pour annuler)

Deux rôles

Streamer (toi)

Tu installes Node, tu génères tes clés, tu publies ta clé publique, tu signes les raids, tu colles la commande dans ton chat.

Viewer (ton chat)

Il installe juste l’extension Chrome T2K. Il n’a pas besoin de clés, ni de Node, ni de ce tutoriel technique.

Ce dont tu as besoin (streamer)

  • Un PC (Windows, Mac ou Linux)
  • Le navigateur Google Chrome (ou Chromium / Edge compatible)
  • Node.js — un logiciel gratuit pour lancer de petits scripts (nodejs.org → bouton LTS)
  • Le projet T2K (dossier téléchargé depuis GitHub)
  • Environ 15–20 minutes la première fois
Astuce Windows : après avoir installé Node, ouvre « Invite de commandes » ou « Terminal », tape node -v puis Entrée. Si tu vois un numéro (ex. v22.x.x), c’est bon.

Pas à pas (streamer)

Récupère le projet

Sur GitHub, télécharge le ZIP du dépôt T2K, ou clone-le :

git clone https://github.com/t12lve/T2K.git
cd T2K

Tu dois être « dans » le dossier T2K pour la suite.

Crée tes clés (une seule fois)

Remplace monpseudo par ton login Twitch en minuscules (celui dans l’URL twitch.tv/monpseudo). 

node cli/generate-keys.js monpseudo

Le script va :

  • créer un fichier secret cli/keys/monpseudo_private.pem → ne le partage JAMAIS, ne l’envoie à personne ;
  • afficher un bloc JSON « publicKey » à copier.
Règle d’or : la clé privée = le code de ta carte bancaire. Si quelqu’un l’a, il peut faire des faux raids en ton nom.

Ajoute ta clé publique dans streamers.json

Ouvre le fichier public/streamers.json avec un éditeur de texte (Bloc-notes, VS Code…).

Colle ton entrée. Exemple de forme :

{
  "streamers": {
    "monpseudo": {
      "displayName": "MonPseudo",
      "trigger": "!raid",
      "publicKey": {
        "kty": "EC",
        "crv": "P-384",
        "x": "…valeurs données par generate-keys…",
        "y": "…valeurs données par generate-keys…"
      }
    }
  }
}

Le login (monpseudo) doit être exactement en minuscules, comme dans l’URL Twitch. Tu peux changer "trigger": "!go" — même valeur dans l’assistant T2K (voir plus bas).

Publie streamers.json (déjà prévu sur GitHub Pages)

Ce site (la page que tu lis) est servi avec le dossier public/. Une fois ton streamers.json mis à jour et poussé sur GitHub (main), il sera disponible ici : 

https://t12lve.github.io/T2K/streamers.json

Dans l’extension, l’adresse à configurer dans extension/content.js doit être : 

const T2K_STREAMERS_URL =
  'https://t12lve.github.io/T2K/streamers.json';
Après modification de content.js, retourne sur chrome://extensions et clique sur Actualiser (icône circulaire) sur T2K.

Installe l’extension Chrome

  1. Ouvre un nouvel onglet et tape : chrome://extensions
  2. Active le Mode développeur (en haut à droite)
  3. Clique Charger l’extension non empaquetée
  4. Choisis le dossier extension du projet T2K (celui qui contient manifest.json)

Tu dois voir apparaître l’extension nommée T2K.

Signe un raid (assistant wizard)

  1. Double-clic sur T2K-Raid.bat (ou npm start)
  2. Au premier lancement : wizard violet Twitch / vert Kick qui explique chaque étape (logo T2K inclus)
  3. Génère tes clés, copie le JSON, charge l’extension
  4. Puis écran Raid → Signer & copier → colle sur Twitch

Les viewers qui ont T2K voient une bannière : « Raid T2K dans 3… ». Échap ou Annuler = stop.

Le trigger de l’assistant doit être le même que dans streamers.json. Exemple : "trigger": "!go" + champ trigger !go dans l’UI.

Variante terminal :

node cli/sign-raid.js monpseudo "https://kick.com/lacible" --ttl 60 --trigger "!raid"

Si tu es juste un viewer

  1. Demande au streamer le dossier extension (ou le lien du dépôt GitHub)
  2. Chrome → chrome://extensions → Mode développeur
  3. Charger l’extension non empaquetée → dossier extension
  4. Regarde le live. Quand un vrai !raid arrive, une bannière apparaît. Tu as 3 secondes pour annuler.

Tu n’as pas besoin de générer de clés. Si la bannière n’apparaît jamais, le streamer n’a peut‑être pas encore publié sa clé publique, ou l’URL dans l’extension est encore le placeholder.

Ça marche pas ?

Symptôme Cause fréquente Que faire
Rien ne se passe après !raid Mauvaise URL JSON, ou login ≠ URL Twitch Vérifie T2K_STREAMERS_URL, recharge l’extension, login en minuscules
« Missing private key » Tu n’as pas lancé generate-keys, ou mauvais login Relance generate-keys avec le bon pseudo
Token rejeté / rien Trop lent : le token a expiré Resigne un raid et colle-le tout de suite
Erreur --ttl too large TTL > 180 Utilise 60 (recommandé) ou max 180
Redirect vers un mauvais site — Impossible si la vérif marche : l’URL est dans le message signé. Si doute, annule (Échap) et désinstalle l’extension

Où sont les fichiers (carte mentale)

T2K/
├── cli/                  ← outils sur TON PC
│   ├── generate-keys.js
│   ├── sign-raid.js
│   ├── raid-app.js       ← assistant navigateur (npm start)
│   └── keys/             ← SECRETS (jamais sur GitHub)
├── T2K-Raid.bat          ← double-clic Windows
├── extension/            ← à charger dans Chrome
│   ├── manifest.json
│   └── content.js
└── public/               ← site GitHub Pages (cette page + streamers.json)
    ├── index.html        ← ce tutoriel
    └── streamers.json    ← clés publiques + trigger
